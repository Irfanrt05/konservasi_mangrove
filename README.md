## Cara Instalasi:

```

```
2. Masuk ke folder
```
cd documents
```
3. Clone repo
```
git clone https://github.com/Irfanrt05/konservasi_mangrove.git
```
4. Tunggu sampai selesai

## Cara Running Program di CMD
1. Pindah ke folder project
```
cd folder_project
```
2. install streamlit
```
pip install streamlit
```
3. Jalankan program dengan
```
streamlit run nama-file.py
```
